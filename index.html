Conversor Gzip / Hex / Base64

Pega un bloque de texto en hexadecimal o base64 (aunque venga rodeado de otras palabras o codigo) y recupera el archivo original, o convierte cualquier archivo a hexadecimal / base64.

Pega aqui el bloque completo tal como lo recibiste (con espacios, saltos de linea, comillas, bloques de codigo o texto alrededor). La herramienta detecta y aisla automaticamente la cadena hexadecimal mas larga, ignorando el resto. Si el contenido resulta ser gzip, se descomprime automaticamente.

Pega aqui el bloque de base64 (con o sin texto alrededor, comillas, saltos de linea). Si al decodificarlo resulta ser un gzip (cabecera 1f 8b), se descomprime automaticamente; si no, se guarda tal cual como archivo binario.

Selecciona o arrastra el archivo que quieres comprimir con gzip y convertir a hexadecimal y/o base64.

Haz clic aqui o arrastra un archivo

Elige si quieres convertir de CSV a JSON o de JSON a CSV.

Pega tu CSV (con encabezados en la primera fila). Se detecta automaticamente coma, punto y coma o tabulador como separador.

Pega un timestamp Unix (segundos o milisegundos), una fecha ISO 8601, o cualquier formato de fecha reconocible. Tambien puedes dejarlo vacio y presionar "Usar ahora".

Todo se procesa localmente en tu navegador; nada se sube a ningun servidor.
